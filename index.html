Back to Bench Support

Back to Bench is a place to save where a hands-on project paused and what to do next.

Before contacting support

  • Include the app version and iOS version.
  • Describe what you expected and the steps that led to the issue.
  • Do not include passwords, private project notes, or other sensitive details.

Contact support via GitHub Issues. Issues may be publicly visible.

Privacy Policy

Project copies

Export creates a JSON copy when you choose to make one. Keep that copy somewhere you control if you want a separate backup. Importing a file changes the projects in the app according to the selected import option; review the app's confirmation before proceeding.
